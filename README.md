# heidiSQL-Ejercicios-Catalogo
Ejercicios SQL - Catalogo de la materia Base de Datos - Instituto Tecnologico Beltran 2026.

Ejercicios hechos en heidi SQL utilizando temas de Catalogo.

Contenido del script:

- Creación de la base de datos prueba_catalogo.
- Creación de las tablas:
  - CLIENTES
  - PROVEEDORES
  - PRODUCTOS
  - VENDEDORES

- Creación de índices:
  - IDX_PRODUCTOS_NOMBRE sobre la columna NOMBRE de PRODUCTOS
  - IDX_CLIENTES_LOCALIDAD sobre la columna LOCALIDAD de CLIENTES

- Consultas al catálogo del sistema (INFORMATION_SCHEMA):
  - Tablas que contienen la columna LOCALIDAD
  - Cantidad de columnas de la tabla PRODUCTOS
  - Usuario actual y cantidad de tablas
  - Tablas que tienen al menos un índice
